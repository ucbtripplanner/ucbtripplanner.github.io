# Research notes — 2026 LA (snapshot 2026-11-08)

Source material behind `../data.js`. Each fact has a source URL; unconfirmed items are marked UNVERIFIED.
These are **notes, not the site** — where they disagree with `data.js` or OPEN_QUESTIONS.md, those are newer.

How this trip was built (multi-agent, 2026-11-08):
1. 5 parallel researchers → the five topic files below
2. 3 itinerary designers (balanced classic / scenic coast / low-stress) → a judge synthesized **itinerary.md**
3. 5 section writers drafted `data.js` (home+course, places, stays, food, prep) with Commons photos and checked pins
4. 9-agent adversarial cross-check (5 fact areas + completeness + desktop/mobile design + Yosemite regression) → fixes
