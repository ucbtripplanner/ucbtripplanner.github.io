# UCB Trip Planner

여행 계획 사이트 → https://ucbtripplanner.github.io

## 구조

```
index.html          # 메인 (여행 목록)
assets/style.css    # 공통 스타일
2026-yosemite/      # 2026 Thanksgiving 요세미티
  index.html
```

## 새 여행 추가하기

1. `2026-yosemite/`를 복사해서 `YYYY-장소/` 폴더 만들기
2. 내용 수정
3. 루트 `index.html`의 여행 목록에 카드 하나 추가
4. push → 1~2분 뒤 사이트에 반영
